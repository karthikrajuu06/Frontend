Working with HTML Lists

This page demonstrates how different types of lists work in HTML, their tags, and how they render in the browser.

1. Unordered List (<ul>)

Used when the order of items does not matter. Items are marked with bullets by default.

  • Apple
  • Banana
  • Orange

2. Ordered List (<ol>)

Used when the sequence of items is important. Items are automatically numbered.

  1. Step 1: Gather ingredients
  2. Step 2: Mix them in a bowl
  3. Step 3: Bake for 20 minutes

Ordered List Custom Attributes

You can use the type attribute to change the numbering style (e.g., Roman numerals, letters).

  1. Introduction (Uppercase Roman)
  2. Body Paragraph
  3. Conclusion

3. Description List (<dl>)

Used to define terms and descriptions, functioning like a dictionary or key-value glossary.

HTML
HyperText Markup Language, the standard language for creating web pages.
CSS
Cascading Style Sheets, used to style and layout web pages.

4. Nested List

You can place a list inside a list item (<li>) to create subcategories or hierarchical levels.

  • Fruits
    • Mango
    • Strawberry
  • Vegetables
    • Carrot
    • Broccoli
